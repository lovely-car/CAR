## 如何使用

1. 点击上方“下载导师评价 Excel”，将 `.xlsx` 文件保存到电脑。
2. 使用电脑端 Microsoft Excel 或 WPS 表格打开。
3. 通过表头的筛选功能选择学校、学院／研究所，再查找导师姓名；也可以用 `Ctrl + F` 搜索。
4. 结合评价原文、评价时间和其他渠道的信息判断，避免只看一个分数。

## 数据来源与评分说明

数据来自原导师评价网（原项目说明中记为后更名“导查查”）。表格包含学校、学院／研究所、导师名、评价文本和“导师打分”等字段。

**“导师打分”是基于 jieba 分词和 SnowNLP 情感分析计算的结果，不是评价者给出的原始评分。** 数值范围为 0—1，较低的值表示模型判断的文本情感更偏负面。情感分析可能误判，不能直接等同于导师的实际指导水平。

评价带有主观性，也可能存在失实、恶意评价或刷好评，请结合原文和其他信息核实。没有检索到某位导师的评价，也不能据此判断其指导质量。

## 择导时还可以了解什么

以下内容整理自原项目中由 ChatGPT 4.0 提供的一般性建议：

- 研究方向是否与你的兴趣和目标相符。
- 导师的指导方式、沟通频率，以及对学生独立工作的要求。
- 课题组的日常氛围、毕业要求和学生去向。
- 实验条件、项目资源和可获得的支持。

条件允许时，联系在读或已毕业的学生，了解具体经历；实地交流也有助于补充网上资料。
